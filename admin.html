Koneksi GitHub (isi sekali) & unggah file

Dipakai oleh tombol Simpan update agar pengaturan langsung tersimpan tanpa unduh file. Butuh personal access token GitHub dengan izin menulis isi repository (Contents: Read and write) hanya untuk repo ini. Pemilik, repository, dan branch diingat di browser ini; token hanya di tab ini dan hilang saat tab ditutup. Jangan bagikan token kepada siapa pun.

Unggah file soal, kunci, atau materi ke GitHub

Nama file harus sesuai kode, mis. LBIND-7.json (soal/kunci) atau PU-M2.json (materi).

Nyalakan saklar pada paket yang boleh dikerjakan siswa; paket yang mati tampil terkunci (🔒). Untuk menambah paket (mis. LBIND-7), klik + Tambah paket. Untuk menghapus, centang kotak hapus pada paket yang dimaksud lalu klik Hapus yang dicentang. Paket baru otomatis mati sampai Anda menyalakannya. Setelah selesai, klik Simpan update.

Tidak perlu dipakai jika sudah memakai Simpan update. Berkas ini untuk soal/pengaturan.json.

Isi judul pada kotak Judul materi baru lalu klik + Tambah materi; kode (mis. PU-M2) dibuat otomatis. Saklar mati = materi tampil terkunci (🔒) di halaman siswa. Judul bisa diubah langsung pada kolomnya. File isi materi diunggah lewat Unggah file materi (nama file sesuai kode, mis. PU-M2.json). Setelah selesai, klik Simpan update.
