Simpan langsung ke GitHub (opsional)

Butuh personal access token GitHub dengan izin menulis isi repository (Contents: Read and write) hanya untuk repo ini. Token disimpan di tab ini saja dan hilang saat tab ditutup. Jangan bagikan token kepada siapa pun.
